# Fieldnotes

A small, responsive e-commerce storefront for thoughtfully chosen everyday goods. Built with plain HTML, CSS, and JavaScript—no install step or build tools required.

## Run locally

Open `index.html` in a browser, or serve the project directory with any static web server (for example, `python3 -m http.server 8000`).

## Features

- Responsive product catalog with search, category filters, and sorting
- Shopping bag with quantity controls, removal, subtotal, and free-shipping progress
- Cart saved in browser local storage
- Demo checkout with basic form validation (no payment processing or backend)
- Accessible controls, reduced-motion support, and graceful product-image fallbacks

Product photography and web fonts load from Unsplash and Google Fonts when an internet connection is available.
